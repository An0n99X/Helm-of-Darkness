# Helm of Darkness

Helm of Darkness is Anubhav Dash's personal security research site.

**Website:** <https://anubhavdash.github.io/Helm-of-Darkness/>

The site is a static Astro project styled with Tailwind CSS.

## Run locally

```sh
npm ci
npm run dev
```

Build the site with:

```sh
npm run build
```

The GitHub Pages workflow builds and publishes the site when changes are pushed to `main`.

## Project layout

- `src/pages/` — homepage and not-found page
- `src/layouts/` — shared page layout and metadata
- `src/styles/` — site typography and responsive layout
- `public/` — images and favicon
